# v3.0.0 — One API, executable provisioning, Kubernetes operator

## Highlights

- Generated Connect/Protobuf contracts power the React control UI, agent-friendly
  management CLI, runtime clients, OpenAPI reference, and `/llms.txt` discovery.
- A unified CLI separates deployment infrastructure (`native`, `k8s`) from
  installation operations (`manage`). Native create performs protected bootstrap
  and installs a hardened systemd service. `create-remote` emits a complete,
  version-pinned installer for review or piping to SSH.
- A controller-runtime Kubernetes operator manages `FunnelControl`,
  `FunnelLoadBalancer`, and `FunnelGateway` resources. The OCI Helm chart installs
  only the operator; component lifecycle is managed through CRs.
- Recreate Deployments retain Secret-backed identities. Control and load balancers
  use PVCs for SQLite and certificates. Gateways keep broker-backed, lease-fenced,
  node-local forwarder identities with no forwarder Kubernetes API permissions.
- Short control updates preserve already-authorized routing within the original
  five-minute signed-configuration window. Upstream authorization lookup errors
  retain existing approvals but cannot authorize a new Service host.
- Native Docker gateways automatically fetch their pinned relay image on a clean
  Docker host. Failed Kubernetes bootstrap Jobs report actionable conditions.
- Tailnet Owner administration remains role-based through verified `users:read`.
  Explicit administrator self-removal verifies a remaining active Owner and is
  audited. Runtime node identity never grants management access by itself.

## Breaking command and deployment changes

```text
native controls|gateways|loadbalancers create/create-remote/list/get/update/delete
native <resource> start/stop/restart/logs NAME
k8s operator create/get/update/delete
k8s controls|gateways|loadbalancers create/list/get/update/delete --context CLUSTER
manage whoami/health/providers/zones/policies/enrollments/nodes/exposures/...
```

The old `control` management namespace, public join/serve/reset/provision paths,
Docker deployment mode, per-component Helm releases, and compatibility aliases are
removed. Hidden runtime entrypoints are generated implementation details.

Replace v2 deployments through explicit cleanup and fresh provisioning. No adoption,
state-import, or migration CLI is provided. Stop old processes before replacement;
never run concurrent processes with one Tailscale identity. Ordinary v3 updates and
stops preserve identity/data. Explicit deletion performs owned cleanup; failures keep
finalizers or cleanup receipts rather than silently abandoning external state.

## Install

Use the binary assets and checksums attached to this release, or the control-only
[quick start](../../README.md#spawn-the-control-node). OAuth credentials stay on
control; additional nodes are created with generated UI/CLI instructions.

```sh
helm show chart oci://ghcr.io/tailscale-x/charts/tailscale-private-funnel --version 3.0.0
docker pull ghcr.io/tailscale-x/tailscale-private-funnel:v3.0.0
```

Linux amd64/arm64 images package the same prebuilt binaries published as assets.
macOS arm64 supports workstation management; native systemd deployment is Linux-only.
Release metadata includes the immutable image digest and OCI chart reference.

## Verification and operating limits

Both Go suites, vet, envtest, reproducible contracts/assets, chart validation, and
image/binary equality are checked. Public acceptance covers the recovered native
control on xvps, native Docker gateways, and the 5090 Kubernetes gateway: Voice,
Flue, MeTube, HTTPS issuance, header sanitization, streaming, and bounded control
maintenance continuity. See [release acceptance](../qa-v3.0.0-release.md) and the
[control-update investigation](../qa-control-update-continuity.md).

No host reboot is required or claimed for this release's acceptance. Control and
broker are singletons. Five-minute continuity is not control-plane HA or indefinite
access: expired configuration and lost identity leases fail closed. Load-balancer
process updates or host failures may interrupt connections. Regional affinity and
full Gateway API conformance are not promised. Live DNS acceptance uses Cloudflare;
GoDaddy and Route 53 have contract tests, not live-account acceptance.

Funnel never changes Tailscale ACLs. Only policy-authorized exposures are published.
DNS deletion is restricted to the exact ownership ledger; reclaiming an unmanaged
record requires explicit, preview-bound approval. Back up SQLite with its matching
encryption/signing keys and Tailscale state, or Kubernetes identity Secrets/PVCs.
Rollback requires the prior binary/image and compatible state; manifest rollback
alone cannot undo a database schema change.
